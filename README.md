# DG Multi Browser — Prototype

Đây là prototype giao diện 10 màn hình điện thoại.

## Chạy thử
Mở `index.html` bằng trình duyệt.

## Lưu ý quan trọng
Nhiều website (YouTube, Facebook, TikTok...) chặn việc nhúng bằng iframe qua chính sách bảo mật. Vì vậy file HTML này chủ yếu dựng giao diện và luồng nhập URL.

Để làm bản chạy thật như một trình duyệt 10 màn hình độc lập, bước tiếp theo nên chuyển sang app desktop dùng Electron/Chromium hoặc Tauri/WebView, với profile/cookie riêng cho từng màn hình.
